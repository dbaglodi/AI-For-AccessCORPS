# Frontend

This folder contains the Angular frontend for the Document Remediation project.

## Features
- Upload `.docx` and `.pptx` files
- Review and edit AI-generated alt text for images
- Download remediated, accessible documents
- High-contrast, accessible UI

## Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   ng serve
   ```
3. Open [http://localhost:4200](http://localhost:4200) in your browser

## Usage
- Upload a document
- Review and edit alt text for each image
- Update alt text and download the remediated file

See the root README for full-stack instructions.
