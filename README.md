# ALADDIN For AccessCORPS


## Repository Navigation
The code for this project is divided into two separate branches based on the environment you wish to use:
* **`colab-notebook` branch:** Switch to this branch to access the Colab notebook version of ALADDIN.
* **`web-app` branch:** Switch to this branch to access the web application codebase.

## ALADDIN Overview
ALADDIN is a tool that scrapes images and their context from a Word or PowerPoint document. It uses AI to generate classifications and alt text descriptions for these images, inputting the generated alt text back into them.
